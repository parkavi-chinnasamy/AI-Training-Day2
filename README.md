# Agentic AI – Day 2 Lab

This project contains the Day 2 practical exercises from the **Agentic AI: Foundations and Open-Source Practice** lab.

The lab focuses on understanding how AI agents reason, use tools, compare reasoning approaches, and improve reliability through multiple attempts.

## 📌 Topics Covered

- ReAct (Reasoning + Acting)
- Tool Calling
- Chain-of-Thought (CoT) comparison
- Self-Consistency
- LLM-based problem solving
- Agent reasoning and tool usage
